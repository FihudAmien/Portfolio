My process, stop by stop

Six stops from the first conversation to launch. Tap a row for details.

StopWhat happensStatus

I gather user requirements, read feedback, and learn the brand guidelines before drawing anything.

Screens and user flows are mapped early, so the team agrees on scope before the visual work starts.

I build clickable prototypes and polished screens from a UI style guide and design system, so every screen stays consistent.

I test with real users and fix what slows them down, such as a checkout page where people drop off.

I work with developers, PMs and business teams, or build the front end myself, and track milestones so the result matches the design.

The app ships to the Play Store and App Store, and feedback loops back into the next version.
